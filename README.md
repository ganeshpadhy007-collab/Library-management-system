# 📚 Library Management System

A responsive web-based Library Management System built with HTML, CSS, and JavaScript.  
Manage books, issue/return books, and track everything directly in the browser using LocalStorage.

**Live Demo:** https://ganeshpadhy007-collab.github.io/Library-management-system/ 
**Tech Stack:** HTML5, CSS3, Vanilla JavaScript, LocalStorage

---

### ✨ Features

- **Add Books** – Add book title, author, and category
- **View All Books** – Display all books in a clean table format
- **Search Books** – Instant search by title or author name
- **Issue Books** – Issue available books to students
- **Return Books** – Return books and update status automatically
- **Track Issued Books** – View all currently issued books with student names
- **Delete Books** – Remove books from the library
- **Data Persistence** – All data saved in browser LocalStorage
- **Responsive UI** – Works smoothly on desktop and mobile
- **Tab Navigation** – Separate tabs for Books and Issue/Return management
